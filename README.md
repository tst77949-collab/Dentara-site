# 🦷 Dentara — دنترا

Futuristic dental clinic website (concept demo, 2049-grade polish).

- **EN default / فارسی (RTL)** with one-click language toggle
- Procedural **3D molar hero** (Three.js r160) — drag to rotate, orange particle cloud
- Widgets: animated counters, 3D tilt cards, journey timeline, before/after smile slider, scripted bilingual chatbot, OSM map, FAQ, contact form demo
- Pure HTML/CSS/JS — no build step, no frameworks
- Design: white × warm orange (#FF8C42), Outfit/Inter/Vazirmatn
